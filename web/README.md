# راهنمای انتشار نسخه وب سامانه udinit روی Netlify و Vercel

این پوشه حاوی نسخه کامل و تحت وب اپلیکیشن **udinit** (HTML, CSS و JavaScript) است که به صورت مستقل و بدون نیاز به نصب هیچ‌گونه ابزار یا وابستگی سروری (Zero-config) بر روی هاست‌های ابری رایگان قابل استقرار است.

---

### روش اول: استقرار بسیار ساده در ۳۰ ثانیه با Netlify Drop (بدون نیاز به گیت‌هاب)
1. وارد سایت [app.netlify.com/drop](https://app.netlify.com/drop) شوید (یا وارد اکانت Netlify خود شوید).
2. پوشه‌ی `web` (شامل فایل‌های `index.html`، `netlify.toml` و `vercel.json`) را بکشید و در کادر Netlify Drop رها کنید (Drag & Drop).
3. بلافاصله پس از چند ثانیه، سایت شما با دامنه اختصاصی رایگان (مانند `udinit.netlify.app`) منتشر و فعال خواهد شد!

---

### روش دوم: انتشار با Vercel (از طریق مخزن GitHub)
1. پوشه `web` را داخل یک مخزن در گیت‌هاب قرار دهید (یا کل پروژه را Push کنید).
2. وارد [Vercel.com](https://vercel.com) شوید و روی **Add New Project** کلیک کنید.
3. مخزن گیت‌هاب خود را انتخاب کنید و اگر کل سورس را آپلود کرده‌اید، گزینه **Root Directory** را روی `web` تنظیم کنید.
4. روی دکمه **Deploy** کلیک کنید. سایت شما با دامنه‌ای مانند `udinit.vercel.app` آماده استفاده خواهد بود.

---

### ویژگی‌های کلیدی نسخه وب:
- **ذخیره‌سازی اطلاعات:** تمامی اطلاعات مشتریان، بدهی‌ها، گزارش تماس‌ها و اسناد تسویه در `localStorage` مرورگر ذخیره می‌شوند.
- **بارگذاری سند پرداخت:** تصاویر فیش و اسناد تسویه به صورت داده‌های امن Base64 در مرورگر نگهداری و در سایز بزرگ قابل مشاهده هستند.
- **تقویم و ارقام شمسی:** تبدیل خودکار تاریخ‌ها و مبالغ به تومان و ریال.
- **پشتیبان‌گیری (Export):** دکمه دانلود خروجی JSON برای نگهداری نسخه پشتیبان روی کامپیوتر یا گوشی.
